# 🥺 ぷゆゆライフゲーム

生きているマスがぜんぶ「ぷゆゆ」になる、コンウェイのライフゲームです。
`index.html` 1枚で動き、ビルドもライブラリも要りません。

## ぷゆゆの一生

ぷゆゆは生き続けた世代数（年齢）で見た目が変わります。

| 年齢 | 見た目 |
| --- | --- |
| 1〜3世代 | 🥹 |
| 4〜15世代 | 🥺 |
| 16〜49世代 | 😭 |
| 50世代〜 | 💀 |

💀 になっても消えるわけではありません。まわりの条件がそろえば生き続けます（ルールは普通のライフゲームと同じ B3/S23）。

## できること

- **再生／停止**（Space）・**1世代すすむ**（→）
- マスをクリック・ドラッグで置く／消す
- ランダム配置・パターン（グライダー、宇宙船、パルサー、グライダー銃など）
- 速さ（1〜60世代/秒）・マスの大きさの調整、盤面の端はつながっています
- **ぷゆゆ口グラフ**：直近360世代のぷゆゆ口を、年齢の段階ごとに積み上げて表示
- **着せ替え**：4段階それぞれの絵文字を自由に変更（プリセット：ぷゆゆ／ひよこ／しょくぶつ／ねこ）。設定はブラウザに保存されます

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、`main` と `/ (root)` を選んで保存
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます
